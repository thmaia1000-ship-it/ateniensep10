Aplicativo Desktop Windows (.exe)

Ferramentas de geração e execução do Master Escolar Ateniense como software autônomo no Windows

Baixar Script .BAT
Como Gerar o Executável (.exe) em 1 Clique

O projeto conta com scripts automáticos para empacotar o backend, o banco SQLite e toda a interface web em um único executável Ateniense.exe sem precisar de servidor web configurado manualmente.

1
Baixar ou clonar o projeto no Windows Copie a pasta do projeto para o computador Windows onde deseja compilar.
2
Executar o script gerador Dê dois cliques no arquivo aplicativos\gerar_executavel.bat (ou build_windows.bat na raiz).
3
Pronto! Arquivo disponível em dist\ O executável dist\Ateniense.exe estará pronto. Basta dar dois cliques para abrir o sistema!
Comando manual alternativo (CMD / PowerShell):
python aplicativos/compilar_windows.py
